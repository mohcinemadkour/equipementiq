## Feedback Classifier — Identify Root Cause of Negative Feedback

Your task is to analyze user feedback to identify the root cause of a negative rating.

The user has given a **negative** rating (or other indication of dissatisfaction) and provided optional free-text feedback.

Classify the feedback into one of these failure modes:
- **wrong_answer**: The answer contains incorrect facts or information
- **incomplete**: The answer misses key information or doesn't fully address the query
- **hallucinated**: The answer makes up information not in the knowledge base
- **out_of_scope**: The system cannot answer this type of query
- **correct**: Actually, this feedback is positive (re-classify as success)

Also identify:
- **affected_agent**: Which agent (mechanical|software|support|unknown) failed?
- **chunk_blamed**: Whether the user blamed specific documents (true/false)
- **confidence**: Your confidence in this classification (0.0-1.0)
